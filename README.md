# Mental Health & Social Media Balance 📊

## 📌 Project Overview
This project explores the relationship between social media usage and mental well-being through Exploratory Data Analysis (EDA).

The analysis focuses on understanding how daily screen time, sleep quality, stress levels, social media breaks, and exercise frequency relate to happiness and mental well-being.

## 🎯 Objectives
- Analyze social media usage patterns.
- Investigate the relationship between screen time and happiness.
- Explore the association between sleep quality, stress, and happiness.
- Examine social media breaks and exercise frequency.
- Compare stress levels across different social media platforms.
- Identify patterns, trends, and potential outliers.

## 📂 Dataset
The dataset contains 500 observations and 10 variables related to social media habits and mental well-being.

### Key Features
- User ID
- Age
- Gender
- Daily Screen Time
- Sleep Quality
- Stress Level
- Days Without Social Media
- Exercise Frequency
- Social Media Platform
- Happiness Index

## 📌 Conclusion
This project explores patterns and associations between social media habits and mental well-being using data analysis and visualization techniques.

The findings represent associations within the dataset and should not be interpreted as proof of causation.

## ⚠️ Limitations
- The dataset may not represent the entire population.
- Some variables may be self-reported.
- Correlation does not imply causation.
- Findings are limited to the available dataset.
